# House of Dime

House of Dime is a nail-tech website I'm currently building with Next.js and Tailwind CSS.

The idea is to create a clean, modern website where clients can explore nail services, view designs and eventually book appointments online.

This project is also part of my journey of getting back into coding, improving my skills and learning through building something practical.

## Project Goals

- Create a modern and responsive website.
- Display available nail services.
- Showcase nail designs and previous work.
- Add client testimonials.
- Allow clients to book appointments.
- Build an admin dashboard to manage bookings and website content.

## Tech Stack

- Next.js
- React
- JavaScript (JSX)
- Tailwind CSS
- MongoDB (planned for database integration)

## Design

I'm going with a soft luxury look, using neutral colours and minimal styling.

| Colour | Hex |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Thapelo-Molosiwa/houseofdime.git
```

Navigate into the project:

```bash
cd nail-tech
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
